# Python-oracle-employee-management-system
Employee management system designed/developed using Python, Oracle Database and PL/SQL packages.

The application demonstrates:
 - Object Oriented Programming
 - Oracle Database connectivity
 - Repository pattern
 - PL/SQL package integration
 - JSON based Data integration
 - Oracle Object types
 - REF cursor based Data retrieval

   ## Features
   - Add Employee
   - Search Employee
   - Update Employee
   - Delete Employee
   - View Employee
  
   ## Technology Stack
     - Python
     - Oracle Database
     - PL/SQL
     - JSON
     - Oracle packages
     - REF cursor (In progress)
     - Object types (In progress)
    
    ## Architecture
     Menu Layer
     |
     Employee Operations
     |
     Employee Directory
     |
     Oracle Package
     |
     Employee Table
